# fantasy-market: Viv World for "A Market Stall Burns at Night"

An emergent-narrative fantasy world built with [Viv](https://github.com/siftystudio/viv), demonstrating how declarative actions, reactions, and plans produce rare, storylike events discovered retrospectively via sifting patterns.

## Overview

**Scale**: ~500 characters across ~60 market stalls, 3 taverns, 2 guard posts, and ~120 homes
**Duration**: 30 in-game days (720 ticks = 1 hour each)
**Seed-driven**: deterministic from a single integer; emergent from random action selection by characters
**Fire frequency**: 0–2 fires per 30-day run (most runs fire exactly once; some zero)

## The Sifting Pattern

The only sifting pattern in this project detects **"a market stall burns at night"**:

```viv
pattern market-stall-burns-at-night:
    roles:
        @stall: as: location
        @keeper: as: character
        @arsonist: as: character
    actions:
        @ignition: from: search: ...
    conditions:
        @stall.kind == #STALL
        @arsonist != @keeper
        @stall.owner == @keeper
        @ignition is set-fire
        ~is-night-at(@ignition.timestamp)
```

When a stall burns at night, the pattern fires and the runtime reports the arsonist, victim, stall, and timestamp—along with a 14-day causal window showing all actions involving the arsonist and victim.

## Fire Paths

**Deliberate (vendetta)**:
- An arsonist with `honor ≤ 3`, `piety ≤ 3`, `secrecy ≥ 6` nurses a vendetta against a vendor
- Conditions: `vengefulness[victim] ≥ 8`, `grudges[victim] ≥ 7`, `shame ≥ 5`, wealth ruined, `courage ≥ 6`, etc.
- Action: `set-fire` queued by the >strike phase of a `vendetta` plan

**Accidental (drunken recklessness)**:
- A drunkard or urchin with `recklessness ≥ 7` and high intoxication/fatigue knocks over a lit brazier
- 30% chance the reaction escalates the fall to a fire
- Less likely but equally valid

Both paths have ~8+ simultaneous conditions, ensuring fires are rare without explicit "fated rival" logic.

## Building & Running

### Install dependencies

```bash
npm install
# Installs @siftystudio/viv-runtime, tsx, lodash, typescript
```

### Compile Viv content

```bash
npm run compile
# Reads src/content/source.viv, outputs src/content/compiled_content_bundle.json
```

### Run a simulation

```bash
# Default: seed=1, scale=phase-a (25 NPCs), days=2
npm start

# Phase-b (30 days, ~100 NPCs):
FM_SCALE=phase-b FM_DAYS=30 FM_SEED=1 npm start

# Full scale (30 days, ~500 NPCs):
FM_SCALE=full FM_DAYS=30 FM_SEED=100 npm start
```

**Output**:
- Last 30 chronicle entries (action gloss + timestamp)
- Sifting pattern results: arsonist, keeper, stall, timestamp, plus 14-day causal window
- Snapshot export to `public/chronicle-seed{SEED}-scale{SCALE}-{DATE}.json`

## Viv-Space Integration

Snapshots are exported in [viv-space](https://github.com/possibly/viv-space) format for interactive chronicle visualization.

### Quick start

```bash
# Generate a snapshot
FM_SCALE=phase-b FM_DAYS=30 FM_SEED=42 npm start
# Creates: public/chronicle-seed42-scalephase-b-2026-05-07.json

# Or use the helper script
FM_SCALE=phase-b ./scripts/generate-snapshot.sh
```

### View in viv-space

```bash
# Clone viv-space
git clone https://github.com/possibly/viv-space.git
cd viv-space
npm install

# Copy the snapshot
cp ../fantasy-market/public/chronicle-seed42-scalephase-b-2026-05-07.json public/sample-chronicle.json

# Run the visualizer
npm run dev
# Open http://localhost:5173
```

**In viv-space**:
- **Nodes**: actions (colored by initiator)
- **Edges**: causal relationships (causes → caused)
- **Filters**: by character, tag, time window
- **Graph**: force-directed layout with pan/zoom
- **Inspection**: click a node to highlight its ancestors (what led to it) and descendants (what it caused)

See [VIV_SPACE_INTEGRATION.md](./VIV_SPACE_INTEGRATION.md) for detailed docs.

## Entity Attributes

### Characters
- **Identity**: name, role (VENDOR, CUSTOMER, GUARD, NIGHTWATCH, DRUNKARD, URCHIN, NOBLE, PRIEST)
- **Status**: location, home, stall (vendors), inventory
- **Resources**: wealth, debts_owed, wares_unsold, hunger, sleepiness
- **Disposition**: pride, piety, thrift, generosity, honor, courage, recklessness, secrecy
- **State**: mood, intoxication, fatigue, health, composure
- **Reactive**: shame, desperation, paranoia, alertness, reputation
- **Social** (per-other-character): grudges, vengefulness, debts_to, affection, rivalry, suspicions, fear, respect
- **Plans**: pursued_target (set by vendetta/other plans)

### Locations
- **kind**: STALL, SQUARE, TAVERN, HOME, GUARD_POST
- **owner** (UID | null): vendor who owns a stall
- **parent** (UID | null): stall's parent is the square
- **flammable**: boolean (set by hazard actions)
- **wares**: UID[] (braziers, oil jars, torches, etc.)

### Items
- **kind**: BRAZIER, OIL_JAR, LANTERN, TORCH, COIN_PURSE, WARE
- **holder** (UID | null): character carrying the item
- **location** (UID | null): location if not held
- **lit**: boolean (for fire sources)
- **oil_level**: numeric (for fuel)
- **inscriptions**: UID[] (oaths, contracts, etc.)

## Authoring Principles

1. **Literal glosses, literal reports**: "Ada knocks over Bren's brazier" not "Ada recklessly plays with fire"
2. **Big attribute soup**: ~20 numeric stats per character; actions nudge them incrementally
3. **Heavy gating**: `set-fire` has 8+ simultaneous conditions; any one missing = action doesn't fire
4. **History-aware conditions**: Chronicle searches for prior oaths, oil spills, quarrels; events shape future
5. **Plans steer the soup**: Vendetta plan phases over days/weeks, gradually ripening an arsonist's desperation
6. **Embargoes prevent thrash**: Actions embargo themselves per-actor/per-role/per-location for realism

## Design Notes

### Why no "fated rivalry"?

Early iterations pre-picked one vendor pair per run to concentrate misfortune on them, boosting fire odds. This worked but felt artificial—the arsonist was *destined*, not *emergent*. Removing fated logic showed that plain daily misfortune (random vendor pairs, tiny drift) suffices: the attribute soup is rich enough that fire conditions naturally ripen for one character per 30-day run, often zero, occasionally two.

### Why so many conditions on `set-fire`?

Every real-world arson story requires motive (vendetta), means (fire source), and opportunity (unwatched, at night). Viv's declarative conditions let us express these precisely:
- Motive: `vengefulness[victim] ≥ 8 AND grudges[victim] ≥ 7 AND shame ≥ 5`
- Means: `near-fire-source(@arsonist) AND stall.flammable == true`
- Opportunity: `~is-night-at(timestamp) AND no-watch-at(@stall) AND believes-unseen(@arsonist)`
- History: `sworn-revenge oracle ≥ 7 days ago` (deliberate path) OR `recent-oil-spill ≥ 2 hours ago` (accidental)

Stacking these makes fires rare—which makes each one a *story* rather than background noise.

## Further Exploration

- **Modify scales**: Edit `SCALES` in `src/main.ts` to test smaller/larger worlds
- **Tune fire gates**: Loosen/tighten conditions in `src/content/actions/hazards.viv::set-fire` to adjust firing frequency
- **Add actions**: Author new actions in `src/content/actions/` and wire them into selectors
- **Add patterns**: Author new sifting patterns in `src/content/patterns/` to detect other stories
- **Inspect attributes**: Modify `src/main.ts` post-run to dump final attribute states for all characters
